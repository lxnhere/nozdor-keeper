# Nozdor Keeper

Клиент **Nozdor** (3.3.5): DXVK / оптимизация / безопасный запуск сессии.

**Демо 3 дня** на один компьютер (один раз на HWID). Дальше — подписка (ключ после оплаты золотом).

[Скачать последний релиз](https://github.com/lxnhere/nozdor-keeper/releases/latest)

## Установка

1. Скачай `NozdorKeeper.zip` из Releases.
2. Распакуй и запусти `NozdorKeeper.exe`.
3. Укажи папку с игрой, активируй демо или ключ.
